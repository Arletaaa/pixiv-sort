# pixiv-sort
pixiv 标签搜索页按收藏数排序的 Tampermonkey 用户脚本：可调抓取间隔、R-18/AI 筛选、分页浏览、一键保存原图。

# pixiv 收藏排序

一个 Tampermonkey 用户脚本，在 pixiv 的标签搜索页把结果按**收藏数**重排，
省去手动翻页找一个题材里最受欢迎的作品。

## 安装

点下面的地址，Tampermonkey 会弹出安装页：

https://cdn.jsdelivr.net/gh/你的用户名/pixiv-sort@main/pixiv-sort.user.js

需要 Chrome / Edge + Tampermonkey。脚本权限只申请两项：
`GM_xmlhttpRequest`（下载原图，绕过跨域限制）与 `i.pximg.net` 域名访问。

## 用法

1. 打开任意标签页，例如 `https://www.pixiv.net/tags/初音ミク/artworks`
2. 点右下角「收藏排序」，再点「开始抓取」
3. 顶部可调基础间隔（实际请求在 0.6–1.4 倍之间随机）、抓取页数、每页显示条数
4. 结果按收藏数从高到低排列，鼠标悬停缩略图出现「⬇ 原图」

## 设置项

| 项 | 说明 |
| --- | --- |
| 基础间隔 | 每次请求前的等待时间，实际值随机浮动 |
| 抓取页数 | 1 页 ≈ 60 条；3 页合并后统一排序 |
| 屏蔽 R-18 | 服务端参数 `mode=safe` |
| 屏蔽 AI 作品 | 服务端参数 `ai_type=1` |
| 保存位置 | Chrome 下载目录，或授权任意本地文件夹（File System Access） |

筛选是服务端参数，改完需要重新抓取才会生效。

## 已知限制

- 收藏数字段依赖 pixiv 内部接口，接口调整可能导致排序失效；脚本内置「补全收藏数」兜底，会逐个请求作品详情。
- 指定文件夹模式由浏览器目录授权实现，Chrome 重启后需重新授权一次。
- 多页作品点一次「⬇ 原图」后需要自己选页，未实现批量下载。
